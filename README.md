# ลอยกระทงคัพ ครั้งที่ 54 — ระบบบริหารจัดการการแข่งขัน & การเงิน

เว็บแอปสำหรับฝ่ายจัดการแข่งขันฟุตบอลลอยกระทงคัพ ครั้งที่ 54 (พ.ศ. 2569)
เทศบาลเมืองกันตัง ร่วมกับ 13 องค์กรปกครองส่วนท้องถิ่น อ.กันตัง จ.ตรัง

รวม 2 ระบบเดิมเข้าเป็นระบบเดียว:

1. **ระบบบันทึกและตรวจสอบการแข่งขัน** — โปรแกรม 68 นัด, บันทึกผลสด, ตารางคะแนนอัตโนมัติ 3 ถ้วย (ก / ข / เยาวชน U17), แบ่งสาย 4 กลุ่ม, ทะเบียน 39 ทีม, ดาวซัลโว
2. **ระบบบันทึกเงินประกันทีม & สปอนเซอร์** — เงินประกัน 3,000 ฿/ทีม, ค่าปรับวินัย (ใบเหลือง 100 ฿ / ใบแดง 300–1,000 ฿ / โทษแบน) หักเงินประกันอัตโนมัติ, ทะเบียนสปอนเซอร์ 5 ระดับ, สรุปรายรับ, คืนเงินประกัน

พร้อม **เอกสาร 4 หมวด** (รายงานผู้ตัดสิน, ใบลงเวลาเจ้าหน้าที่, บันทึกคาดโทษ, ใบเปลี่ยนตัวนักกีฬา)
และการตรวจคุณสมบัตินักกีฬา 14 อปท. พิมพ์รวมเล่มได้ในคลิกเดียว

## การใช้งาน

```bash
npm install
npm run dev      # พัฒนา
npm run build    # สร้างเวอร์ชันใช้งานจริงใน dist/
```

นำโฟลเดอร์ `dist/` ไปวางบนเว็บเซิร์ฟเวอร์หรือเปิดผ่าน GitHub Pages ได้ทันที

## การเก็บข้อมูล

- ข้อมูลทั้งหมดบันทึกอัตโนมัติในเบราว์เซอร์ (localStorage) ของเครื่องที่ใช้งาน
- รองรับ **ส่งออก/นำเข้าไฟล์สำรอง JSON** เพื่อย้ายเครื่องหรือสำรองข้อมูล (เมนูด้านล่างทุกหน้า)
- ไม่ต้องใช้เซิร์ฟเวอร์หรือฐานข้อมูล
